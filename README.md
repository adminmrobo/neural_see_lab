# 신경망이 보는 법 연구실 — 신경망은 고양이를 어떻게 "볼까" (neural_see_lab)

> 사진 한 장이 숫자가 되고, 선이 되고, 귀·눈·입이 되어 "고양이"라는 답이 나오기까지 무슨 일이 일어날까?

박사가 내일 아침 쪽지시험을 예고했습니다. 범위는 「신경망이 우리를 '보는' 방식」 네 단계, 본 문항 4개에 보너스 1개.
숫자에 약한 인턴1 시아와 "왜"를 말로 하기 어려운 인턴2 모아가 조수 하루와 함께 준비합니다.
출제위원 박사(원리와 함정)·초파리 연구원(생물의 눈과 비교)·주판봇(직접 계산)이 출제 가이드를 주고, 미공개 식구 X1~X3가 교보재(픽셀 격자판·필터 카드·풀링 체·부품 스티커)를 나르며 진행을 돕습니다.

- 사이트: https://adminmrobo.github.io/neural_see_lab/
- 저장소: https://github.com/adminmrobo/neural_see_lab
- 분야: 인공지능 (컴퓨터 비전 · 합성곱 신경망)
- 참고 영상: 사용자가 제공한 짧은 영상 「HOW A NEURAL NET SEES · PART 8」(약 20초, 제작자 표기 없음)의 4단계 흐름. 그림·숫자·코드·대사는 이 연구실이 새로 만들었습니다.

## 구성 (한 페이지 · `index.html`)

| 차례 | 내용 | 실험 도구 |
|---|---|---|
| 처음 오신 분께 · 출제 가이드 · 큰 그림 | 3줄 요약, 출제위원 세 명의 출제 방향, 두 인턴의 약점과 하루의 처방, 문항 ↔ 단계 대응표 | — |
| 1 사진은 숫자 격자 (시험 1번) | 픽셀마다 진하기 숫자 하나, 16×16 = 256개 | 픽셀 격자판 (픽셀을 눌러 바꾸기) |
| 2 3×3 필터가 196곳을 훑는다 (시험 2번) | 곱해서 더하기, 부호는 방향·크기는 세기 | 필터 훑기 (필터 카드 4장, 재생·한 자리씩) |
| 3 ReLU와 풀링 (시험 3번) | 음수는 0, 2×2마다 최댓값, 14×14 → 7×7 | ReLU 스위치·풀링 체 (최댓값 vs 평균) |
| 4 깊은 층이 부품·전체로 (시험 4번) | 보는 범위 3 → 18, 부품의 개수가 아니라 자리까지 | 보는 범위 막대 · 부품 판정 (뒤섞인 고양이) |
| 대결 | 1픽셀 옮긴 고양이: 풀링한 지도 vs 풀링 안 한 지도 | 옮기는 방향 고르기 |
| 본 시험 | 쪽지시험 4문항 + 보너스, 입력 채점(저장 안 함), 문항별 해설과 돌아갈 단계 | — |
| 정리 · 아웃트로 · 지식 색인 · 꾸러미 | 시험 전날 밤 한 장, 비유의 한계, 다음 공부(역전파) | 색인 검색, 온톨로지·서지 내려받기 |

## 핵심 숫자 (`code/analysis.py` 재현)

| 무엇 | 값 |
|---|---|
| 16×16 그림의 숫자 / 3×3 필터가 멈추는 자리 | 256개 / 196곳 (14×14) |
| 손계산 예 (세로 경계 필터) | 자리 15번 +2.5, 자리 71번 −3.0 (반대 방향 경계) |
| 고양이 세로 경계 지도: 양수 / 음수 | 59곳 / 59곳 |
| 1픽셀 옮긴 고양이의 지도 닮음 (오른쪽 · 아래) | 풀링 83.4% · 83.8% / 풀링 안 함 64.4% · 49.5% |
| 2픽셀 옮긴 고양이 (오른쪽) | 풀링 64.3% / 풀링 안 함 37.1% |
| 보는 범위 (1층 필터 → 3층 필터) | 3 → 4 → 8 → 10 → 18 |
| 부품 판정 (찾은 부품 · 개수 판정 · 자리 판정) | 고양이 5·○·○ / 뒤섞인 고양이 5·○·× / 집 3·×·× / 컵 1·×·× |

## 데이터와 숫자 표시 원칙

- 그림 4장(고양이·집·컵·뒤섞인 고양이)은 16×16, 진하기 0·0.5·1로 만든 설명용입니다.
- 필터 네 장은 사람이 정한 소벨 필터(세로·가로)와 그 반대 방향입니다. 실제 신경망의 필터는 수십~수백 장이고 학습으로 정해집니다.
- 부품 탐지기는 고양이의 풀링 지도에서 귀·눈·입 자리를 떼어 만든 본보기이고, "찾음" 문턱 80%와 판정 규칙(개수 4개 이상 / 귀 → 눈 → 입 순서와 좌우 배치)도 설명용으로 사람이 정했습니다.
- 페이지 안 모든 실험은 `build/nsee.js`가 브라우저에서 직접 계산하고, 같은 계산을 `code/analysis.py`가 `data/results.json`에 남깁니다. `build/check_numbers.js`가 둘이 같은지 맞춰 봅니다.

## 폴더

```
index.html                   해설 페이지 (외부 라이브러리 없음, 글꼴만 외부)
code/analysis.py             그림·필터·풀링·대결·부품 판정 계산 (모든 본문 숫자의 원본)
data/nsee.json               페이지에 싣는 그림·필터·부품 본보기 자리
data/results.json            analysis.py 결과
build/                       페이지 생성 (python3 build/build_all.py), 숫자 검산(check_numbers.js), 브라우저 점검(check_browser.py)
kg/index/                    지식 색인 원본 kg.json · refs.json · meta.json · check_report.md
docs/                        표지 지시문(16비트 RPG 픽셀아트, Genspark용) · 이미지 제작 명세서 · 페르소나 감사 보고서
img/                         표지 그림 자리 (cover_00.webp를 넣고 다시 빌드하면 대체 표지 대신 보임)
cover_manifest.json          표지·온톨로지 현황 (ahnboat_lab_cover_status가 수집)
KG_new_ids.json              시리즈 등록부에 더할 새 개념 ID
```

## 다시 만들기

```bash
python3 build/build_all.py                              # 숫자 → 페이지 → 지식 색인·꾸러미 → 표지 문서 → 숫자 검산
python3 build/check_browser.py index.html               # 콘솔 오류·390/1280px 가로 넘침·빈 캐릭터 그림 점검 (playwright)
```

캐릭터 그림은 `adminmrobo/ahnboat_lab_explainer`의 캐릭터 팩(`packs/character/character_pack`)에서 가져옵니다. 다른 곳에 받아 두었다면 `LAB_PACK` 환경 변수로 경로를 알려 주세요.

캐릭터(박사·조수 하루·초파리 연구원·주판봇·인턴 시아·인턴 모아·X1~X3)의 이름·설정·그림 저작권은 안상선에게 있으며 허락 없이 쓸 수 없습니다.
