# 페르소나 감사 — 신경망이 보는 법 연구실 (index.html, 첫 판)

- 대상: `index.html` 첫 판 (커밋 「쪽지시험 대비반 첫 판」), 1280·390px 화면과 브라우저 동작 확인
- 작성자와의 관계: 자기 결과물 (같은 작업에서 만든 페이지) → 빈 곳·오류를 먼저 찾음
- 척도: 5점 만점, 0.5 단위

## 0. 대상 요약

한 페이지짜리 연구실 해설이다. 박사가 쪽지시험을 예고하고, 숫자에 약한 시아와 "왜"에 약한 모아가 조수 하루와 함께 네 단계(숫자 격자 → 3×3 필터 → ReLU·풀링 → 깊은 층의 부품과 자리)를 준비한다.
단계마다 왜 상자·조수 수식 상자·생물 비교·교보재(X1~X3)·대화·실험 패널·모의 문제·확인 퀴즈가 있고, 대결(1픽셀 옮긴 고양이, 풀링 vs 풀링 안 함), 입력 채점형 본 시험(4문항 + 보너스), 정리, 지식 색인·꾸러미로 끝난다.
모든 숫자는 `code/analysis.py`로 재현되고 페이지 계산과 대조된다.

## 5. 정리

입문 쪽(A·F)은 손계산·모의 문제·처방 구조를 높게 봤지만, 화면 결함(빈 말풍선, 모바일 겹침)에 점수가 깎였다. 숫자·교육 쪽(C·D)은 재현성과 문항 대응표를 좋게 봤고, 시험 문항의 변별력(모의 문제와 같은 답, 선택지 힌트)을 가장 큰 흠으로 꼽았다. 전문가(E)는 큰 줄기와 한계 표시는 정확하다고 봤으나 복합 세포의 연도 서술을 지적했다.
입문 독자와 전문가 점수 차는 0.5점으로, 완료 기준(1점 이내)을 넘지 않는다. 비용 대비 효과가 가장 큰 과제는 ① 시험 2번 교체 ② 빈 말풍선 숨기기 ③ 복합 세포 정정이며, 1~6순위를 이번 판에 반영했다.
