# 신경망이 보는 법 연구실 — 이미지 제작 명세서

## 1. 그림체와 고정 외형

- 그림체: 16비트 RPG풍 픽셀아트 (굵은 어두운 외곽선, 2~3단계 명암, 작은 반사광). 캐릭터 팩 `CHAR_lab4`를 따릅니다.
- 장면 조명: 낮의 연구실. 흰 벽, 큰 창의 자연광, 연보라·민트·분홍 소품. 밤·어둠·네온은 쓰지 않습니다.
- 고정 외형: 박사·조수(하루)·초파리 연구원·주판봇 v2·인턴 시아·인턴 모아. X1~X3는 본문 교보재 담당으로만 나오고 표지에는 넣지 않습니다.
- 그림 안 글자·숫자·로고 금지.

## 3. 일관성 지침

- 표지는 시험 전날 장면입니다. 아웃트로(합격)의 표정을 미리 쓰지 않습니다. 시아는 살짝 긴장, 모아는 생각하는 얼굴, 하루는 단단한 얼굴.
- 초파리는 왼쪽에서 오른쪽을, 주판봇은 오른쪽에서 왼쪽을 봅니다.
- 칠판의 고양이는 이 페이지의 16×16 고양이와 같은 모양(뾰족한 귀 둘, 네모 눈 둘, 회색 코와 입)으로 그립니다.
